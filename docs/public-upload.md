# 公共目录上传与下载恢复

2026-11-15 起，采集结束并保存后自动执行上传与续采进度同步；下述按钮用于补传、重试或独立上传。开始和上传时会提醒当天已有采集记录。上传成功后再换电脑；详见 [跨电脑续采](cross-pc-progress.md)。

默认保存位置：`\\172.16.4.2\aim\shared\CFIMAGE-20261113\eeg-data`。
这是经过读写验证的 SMB 公共目录，不使用目前未授权的 oi-data S3 桶。

结束采集并等待保存完成后，在原工作台点击“上传当前被试全部数据”。
也可以双击 `上传被试数据.bat`，选择已有数据的 `data/native` 文件夹，再选择被试编号上传。
这个独立入口不下载图库，也不连接脑电设备。首次使用沿用 NAS 离线运行环境安装机制。
如果从新文件夹运行上传工具，必须选中原采集程序的数据目录，空列表不代表数据丢失。

带授权的分发版本首次启动会把便携授权导入 Windows 当前用户的 DPAPI 文件，随后自动登录 NAS。
凭据保存在 `%LOCALAPPDATA%\CFIMAGE\smb-upload.dpapi`，不进入 EEG 或上传清单。
Windows 1219 表示当前已有其他账号连接 NAS；程序会报错，不强制断开正在使用的连接。
更换 Windows 用户需要重新安装授权包。便携授权包含可恢复的安装材料，不是只有程序可读的秘密。

上传内容包含所选被试在本机的全部原生会话、连续 EEG SQLite、wire_archives 网络原始包及接收时序、
图片事件、配置、试次计划、按被试过滤的进度库，以及存在时的 `sub-编号` 导出目录。
不会上传其他被试，不会自动抓取其他电脑数据，不删除本地数据，不自动修改有效试次。
必须结束采集并完成会话收尾后上传；采集设备锁和未结束会话检查会阻止边采边备份。

目录按 `sub-编号/电脑随机标识/objects/内容哈希` 保存，避免不同电脑互相覆盖。
逐文件读回核对 SHA-256，全部通过后才发布 `snapshots/清单哈希.json`。
重复上传跳过已经一致的文件；中断后重新点击可继续复用已上传的对象。
SQLite 使用一致性备份并检查数据库完整性。上传成功不代替脑电质量、漂移或刺激对齐检查。

每次成功在本机 `reports/transfers/` 留下收据，含 `snapshot_key` 和 NAS 完整路径。
恢复到空目录：

```
.venv\Scripts\python.exe -m src.nas_transfer restore --snapshot "sub-编号/电脑标识/snapshots/清单哈希.json" --output "D:\EEG-restore"
```

也可以把 NAS 上该被试的整棵目录先复制到本地保管，但哈希对象需要通过恢复功能重建原始文件名。
数据读取权限已用同一 NAS 账号实测验证。公共目录不是个人独占存储区域。
